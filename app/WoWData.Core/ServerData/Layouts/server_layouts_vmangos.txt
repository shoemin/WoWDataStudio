# WoW Data Studio: what the tables of the VMaNGOS world database mean (0.9.0, the Server data tab).
#
# The world server (VMaNGOS mangosd) keeps items, creatures, quests, game objects, spells, loot, vendors, trainers,
# areas, maps, flight points and factions in its MySQL world database ("mangos"). The column NAMES AND TYPES always come
# from the live database itself (SHOW COLUMNS): this file only adds what they mean, so a column that is not described
# here is still shown and edited, raw, with a hint. The facts below were read from the VMaNGOS schema and its loaders
# (ObjectMgr / SpellMgr: which rows a 1.12 server loads, the checks it makes at start) and checked on the database of
# this machine (schema migration 20231231082728); no server code is copied.
#
# @kind <name> = <table>.<key column> <label column> [| plain name]   ("*": a list of rows, named by its size)
#     an object other columns link to ("-> item"). Links to the client's tables: "-> dbc:<Table>".
# @enum / @flags <Name>, then "  <value> = <text>" lines. Named values of the DBC layouts (Race, ClassMask,
#     SpellSchool, SpellEffect, AuraType, ...) can be used too.
# [table]
#   about:    what the table controls, in plain words
#   label:    the column that names a row (in links and lists)
#   version:  patch        one row per entry and content patch (`patch`): the server uses the row with the highest
#                          patch <= its WowPatch (mangosd.conf; 10 = 1.12)
#             build        one row per entry and client build (`build`): the row with the highest build <= 5875
#             build=       only the rows of build 5875 are loaded
#             patch-range  `patch_min` .. `patch_max`: the row is loaded when the server's patch is in the range
#             build-range  `build_min` .. `build_max`: loaded when 5875 is in the range
#   reload:   the GM command that reloads the table while the server runs (".reload ..."), or "restart"
#   == Group  starts a group of columns in the details panel
#   column [semantic] [-> link [modifier]] [| hint]
#     semantic: id  patch  text  bool  enum(Name)  flags(Name)  money (copper)  ms  seconds  percent  coords
#     link modifiers: zero (0 is a real row: map 0), abs (the absolute value links), neg (only a negative value links, as -value),
#                     sign(<kind>) (a negative value links to <kind> instead, as -value)
#     Name[N] makes Name1..NameN; Name_[N] makes Name_1..Name_N. A "~" before the name: a best guess (not verified).
