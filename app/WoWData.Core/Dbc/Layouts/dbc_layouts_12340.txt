# WoW Data Studio: the DBC layouts of the World of Warcraft 3.3.5a client (build 12340), Wrath of the Lich King.
# Experimental and read-only: used by "Other versions" (DbcLayouts.ForBuild(12340)). There is no WotLK server here, so
# every table is "server: client".
#
# One [Table] section per DBFilesClient\<Table>.dbc. The keys of a section:
#   category:     where the table is listed in the editor
#   about:        what the table controls in the game, in plain words
#   server:       always "client" in this file
#   label:        the column that names a row in links (default: the first named text column)
#   evidence:     where the layout comes from
# Then one line per column, in file order:
#   Name[N]  [storage] [semantic] [-> LinkedTable] [=> server thing] [| hint]
#   storage:  int  uint  float  string  loc (16 languages + a flags field = 17 fields from TBC on)  byte  ushort
#   semantic: id  bool  enum(Name)  flags(Name)  flags  icon  texture  model  path
#   Name[3] makes Name1, Name2, Name3. A "~" before the name: the meaning is a best guess (shown as not verified).
#   col_N: an unknown column (N = its field index), shown as stored.
#
# Evidence used (every layout was measured on Blizzard's copy of each file: the archives of the 3.3.5a client without
# the private-server patch-7.mpq, which replaces some tables; where patch-7's copy has another shape it is said so):
#   * the file itself: field count and record size (every column below adds up to them; all 3.3.5a tables have 4-byte
#     fields), which fields are valid string-block offsets in every row, value ranges, float bit patterns, and links
#     that resolve to the IDs of another table (the check program reports the resolve rate of every "->" link; a link is
#     only kept when at least 95% of its non-zero values resolve);
#   * value matching with the verified 1.12.1 layouts (dbc_layouts_5875.txt, checked against the 1.12.1 client) and with
#     the 2.4.3 (8606) client: a 3.3.5a field whose values equal a known column on (nearly) all rows with the same ID is
#     that column (numbers compared as 32-bit values, strings as text). The evidence line gives the match rate. A 1.12
#     "loc" string is 9 fields, a 2.4.3/3.3.5a one 17, so every column after a localized string moves by 8 fields;
#   * public format knowledge (wowdev.wiki-style descriptions of the 3.3.5a records) for the names of columns that are
#     new since 1.12 or whose values changed: marked "(wowdev)" in the evidence line. Such a name is "~" unless the file
#     confirms it (its values fit the meaning, its link resolves).
# The client executable was not read for this file.
