# WoW Data Studio: the DBC layouts of the World of Warcraft 2.4.3 client (The Burning Crusade, build 8606).
#
# Experimental, read-only: used by the "other versions" reader (Versions\OtherClients.cs). The format is the one of
# dbc_layouts_5875.txt (1.12.1); see the header there. In short, one [Table] section per DBFilesClient\<Table>.dbc:
#   category:     where the table is listed in the editor
#   about:        what the table controls in the game, in plain words
#   server:       always "client" here (we have no 2.4.3 server)
#   label:        the column that names a row in links (default: the first named text column)
#   evidence:     how the layout was established
# Then one line per column, in file order:
#   Name[N]  [storage] [semantic] [-> LinkedTable] [| hint]
#   storage:  int  uint  float  string  loc (16 languages + a flags field = 17 fields)  byte  ushort
#   semantic: id  bool  enum(Name)  flags(Name)  flags  icon  texture  model  path
#   Name[3] makes Name1, Name2, Name3. A "~" before the name: the meaning is a best guess (shown as not verified).
#   col_N: an unknown column (N = its field index), shown as stored.
#
# Evidence (every table was measured on the enGB 2.4.3.8606 client, the winning copy of each file in the client's own
# archive order; scratch probes in the session's scratchpad\layouts_8606):
#   * value matching against 1.12.1: for each column of the verified 1.12 layout (dbc_layouts_5875.txt), the 2.4.3
#     field that holds the same value on the rows with the same ID (text compared as text). Rates are given per table;
#     "nd" = the rate on the rows where the 1.12 value is not the column's most common value (so a column that is
#     mostly 0 or -1 cannot match by accident). A localized string grows from 9 to 17 fields, so every column after
#     one moves by 8;
#   * the file itself: which fields are string offsets (and what the text says), float bit patterns, value ranges,
#     and links that resolve to the IDs of the linked table (the rates are in each evidence line);
#   * format knowledge: names of columns new in 2.4.3 follow the public descriptions of the format (wowdev); such a
#     name is plain only when the file confirms it (a link that resolves, text that says it, a box whose minimum is
#     below its maximum), otherwise it starts with "~".
# Localized strings: the English text of this enGB client is in slot 0 of the 16 (the slots of the other languages
# are empty), as in 1.12.
